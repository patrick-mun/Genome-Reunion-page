# Preuves — Sécurité, AIPD et audits

À conserver uniquement dans l’environnement institutionnel sécurisé :

- [ ] AIPD complète, datée et versionnée ;
- [ ] validation / avis du DPO ;
- [ ] registre des risques et plan de traitement ;
- [ ] architecture technique détaillée ;
- [ ] politique de sécurité ;
- [ ] matrice des habilitations ;
- [ ] preuves de revues périodiques des droits ;
- [ ] preuves MFA / RBAC ;
- [ ] politique de journalisation ;
- [ ] preuves de sauvegarde et restauration ;
- [ ] rapports d’audit ;
- [ ] rapports de tests de sécurité / vulnérabilité ;
- [ ] procédures d’incident et violation de données ;
- [ ] preuves de traitement des incidents ;
- [ ] procédures de départ / retrait des accès.

Ne jamais déposer ici les détails techniques exploitables, secrets, comptes, journaux réels ou vulnérabilités.
