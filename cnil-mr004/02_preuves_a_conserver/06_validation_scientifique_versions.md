# Preuves — Validation scientifique et gestion des versions

À conserver :

- [ ] protocole scientifique final daté ;
- [ ] versions antérieures significatives ;
- [ ] preuve de validation scientifique interne ;
- [ ] décisions de modification substantielle / non substantielle ;
- [ ] historique des changements de finalité, population, données ou méthodes ;
- [ ] dictionnaire des données versionné ;
- [ ] méthodes analytiques versionnées ;
- [ ] versions des logiciels / pipelines nécessaires à la reproductibilité scientifique ;
- [ ] rapports de contrôle qualité ;
- [ ] justification des modifications de sélection WGS ;
- [ ] liste des publications et date de dernière publication liée à l’étude ;
- [ ] rapport final de recherche lorsqu’il existe.

Les éléments scientifiques non sensibles peuvent être publics ; les documents internes validés ou contenant des informations de sécurité doivent rester dans l’espace CHU approprié.
