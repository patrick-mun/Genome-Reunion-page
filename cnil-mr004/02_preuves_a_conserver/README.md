# Génome Réunion — Preuves de conformité à conserver

**Important : ce dossier GitHub public ne doit contenir que l’inventaire des preuves, jamais les originaux confidentiels ou nominatifs.**

Les originaux doivent être stockés dans un espace institutionnel sécurisé du CHU avec contrôle d’accès et gestion des versions.

## Catégories de preuves à conserver

### A. Formalités et gouvernance RGPD
- preuve de l’engagement / déclaration de conformité MR-004 du responsable de traitement ;
- preuve d’enregistrement du projet dans le répertoire public PDS ;
- fiche du registre des activités de traitement ;
- validation DPO / DRCI de la qualification réglementaire ;
- identification formelle du responsable de traitement ;
- justification de la base légale et de l’intérêt public.

### B. Protocole et validation scientifique
- protocole scientifique daté et versionné ;
- validation scientifique ;
- historique des versions ;
- dictionnaire de données ;
- méthode analytique ;
- liste/version des sources externes.

### C. Information et droits
- note d’information validée ;
- document d’accord / preuve d’information selon le circuit retenu ;
- procédure d’opposition / retrait ;
- procédure d’exercice des droits ;
- preuve de gestion des versions remises aux participants.

### D. Acteurs et contrats
- convention EFS–CHU ;
- documents CRB ;
- contrats des plateformes ;
- clauses article 28 RGPD ;
- accord article 26 si responsabilité conjointe ;
- engagements de confidentialité ;
- documents de transfert de données le cas échéant.

### E. Sécurité et AIPD
- AIPD complète et versions successives ;
- validation DPO ;
- politique de sécurité ;
- matrice des habilitations ;
- preuves de revue des droits ;
- tests de sauvegarde / restauration ;
- rapports d’audit et tests de sécurité ;
- procédures d’incident / violation ;
- preuves de traitement des incidents.

### F. Sources externes
- accession et version 1000G / IGSR ;
- demandes EGA ;
- décisions DAC ;
- DAA signés ;
- restrictions d’usage ;
- dates d’accès / expiration ;
- preuve de suppression ou fin d’accès si exigée.

### G. Échantillons / CRB
- enregistrement du programme / collection si nécessaire ;
- procédure de réception ;
- traçabilité des échantillons ;
- règles d’aliquotage ;
- preuve de destruction le cas échéant ;
- procédure de retrait participant.

## Règle de conservation documentaire

Chaque preuve doit être identifiable par : **type – version – date – propriétaire – validateur – emplacement sécurisé – durée de conservation – lien avec l’exigence MR-004 correspondante**.
