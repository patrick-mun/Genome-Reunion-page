# Acteurs, flux et responsabilités — MR-004

**Statut :** trame à compléter

## Acteurs à qualifier

- CHU de La Réunion ;
- service de génétique moléculaire ;
- DRCI ;
- DPO ;
- DSIO ;
- CRB ;
- EFS La Réunion ;
- POPgen ;
- plateforme de génotypage ;
- plateforme de séquençage ;
- hébergeur éventuel ;
- partenaires scientifiques.

## Pour chaque acteur

Documenter :

- rôle opérationnel ;
- rôle RGPD ;
- données reçues ;
- accès autorisé ;
- finalité propre ou sur instruction ;
- durée de conservation ;
- possibilité ou non de réutilisation ;
- localisation des données ;
- contrat / convention applicable.

## Flux à cartographier

**source → donnée → transformation → stockage → utilisateur → destination**

Au minimum : EFS → CRB → extraction → équipe de recherche → génotypage → WGS → stockage → analyse → résultats / publication.

- matrice RACI / RGPD ;
- schéma de flux ;

- accords de responsabilité conjointe le cas échéant ;
- conventions EFS / CRB / plateformes.
