# Sécurité et AIPD — MR-004

**Statut :** trame à compléter avec DSIO / DPO

## Sécurité à documenter

- hébergement et localisation des données ;
- séparation développement / test / production ;
- chiffrement au repos et en transit ;
- gestion des clés ;
- MFA ;
- RBAC ;
- journalisation et audit ;
- revue des habilitations ;
- sauvegardes et restauration ;
- segmentation réseau ;
- exports ;
- supports amovibles ;
- transferts ;
- gestion des vulnérabilités ;
- incidents et violations de données.

## AIPD

Méthode retenue :

**menace → événement redouté → probabilité → gravité → mesures existantes → mesures supplémentaires → risque résiduel**

Risques à couvrir notamment :

- unicité du génome ;
- ré-identification ;
- parenté et apparentés ;
- ascendance ;
- variants rares ;
- données familiales ;
- accès interne abusif ;
- compromission de compte ;
- publication ;
- transferts ;
- conservation longue ;
- membership inference ;
- reconstruction à partir de données agrégées.

> Ne jamais publier dans ce dépôt public l’AIPD détaillée, la cartographie de sécurité sensible, les secrets, les comptes ou les vulnérabilités. Seules les trames et versions expurgées peuvent être présentes ici.
