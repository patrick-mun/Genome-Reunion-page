# Note d’information individuelle — Génome Réunion

**Statut :** trame à rédiger ultérieurement à partir du modèle Starter Kit MR-004  
**Ne pas utiliser comme version participant tant qu’elle n’est pas validée DPO / DRCI / EFS.**

## Rubriques à prévoir

- identité du responsable de traitement ;
- coordonnées du DPO ;
- finalités du projet ;
- caractère volontaire de la participation ;
- origine du reliquat EDTA ;
- examen des caractéristiques génétiques ;
- catégories de données traitées ;
- pseudonymisation et rôle de l’EFS ;
- destinataires / partenaires ;
- sources externes utilisées pour comparaison ;
- durée de conservation ;
- droits et modalités d’exercice ;
- opposition / retrait ;
- conséquences d’un retrait après agrégation ou publication ;
- découvertes génétiques potentiellement pertinentes ;
- possibilité de ne pas être informé si le cadre juridique l’exige ;
- transferts éventuels ;
- réclamation auprès de la CNIL.

## Preuves associées à conserver hors GitHub public

- version validée et datée ;
- preuve de validation institutionnelle ;
- preuve de remise / information selon le circuit EFS ;
- versions successives et historique des modifications.
